# Pirates! Couch Co-op v0.15 (pre-release)

> ## ⚠️ GOG version 2.0.0.4 ONLY
> **This mod works ONLY with the GOG.com version of Sid Meier's Pirates! (2004), installer 2.0.0.4
> (game version 1.0.2.0, build 30927). It will NOT work with any other store version of the game - not Steam,
> not retail CD/DVD, not any other release or patch.** On any other version the mod switches itself off and the
> game runs without it.

First public test release of the Sid Meier's Pirates! (2004) couch co-op + controller + widescreen mod.

**Requires your own copy of the game: GOG version 2.0.0.4 (game 1.0.2.0).** Other versions are not supported; the
mod switches itself off with a message if `Pirates!.exe` is not the supported one.

Install: copy `version.dll` and `PiratesCoop.ini` into the game folder (next to `Pirates!.exe`). See README.md.

Known issues: don't Alt+Tab while the game runs (can crash with R6025); fleet size limited by the game;
Player 1 vs Player 2 sword fights are new.
